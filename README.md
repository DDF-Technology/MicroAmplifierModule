# MicroAmplifierModule

Archivio tecnico e produttivo di un modulo micro-amplificatore basato su TDA2822.

## Contenuto

- distinta base (`BOM`);
- coordinate per assemblaggio pick-and-place;
- pacchetto Gerber e forature per la produzione del PCB;
- immagini e materiali grafici storici.

Il progetto conserva gli artefatti originali senza modificarne formato o contenuto.
